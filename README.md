# Machine Learning Lab

**Coursework experiments in classification, regression, game-playing, and tokenization.**

These notebooks document problem framing, data preparation, model comparison, and interpretation. They are learning projects—not production models or independently validated research results.

## Explore

- [Email spam classification](spam-classifier/Project_1.ipynb): an initial workflow for separating spam from legitimate email.
- [San Francisco housing price prediction](sf-housing/Project_2.ipynb): data preparation, leakage-aware feature selection, and random-forest regression.
- [Customer purchase and return classification](customer-outcomes/Project_3.ipynb): classification across purchase, return, and non-purchase outcomes.
- [Email feature classification](email-features/Project_4.ipynb): text cleaning and engineered features for spam classification.
- [Tetris game playing](tetris-ai/Project_6.ipynb): experiments with a provided game framework.
- [Wikipedia BPE tokenizer](bpe-tokenizer/): text extraction, tokenizer training, and train/test preparation scripts.

## Reading and reproducing

Open notebooks on GitHub for saved explanations and outputs, or use Jupyter in a dedicated Python environment. Inspect imports, dataset paths, and setup cells before running: projects were developed in different course environments and do not share a pinned dependency set.

Some datasets and framework components were supplied for coursework. Their availability and reuse rights should not be assumed. Saved outputs describe a particular run, not a guarantee of reproducible or out-of-sample performance. Earlier notebooks retain their course structure so the progression remains visible.
